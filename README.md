# 🔗 URL Shortener

A modern, responsive, and production-ready **URL Shortener** built with **HTML5, CSS3, and Vanilla JavaScript**. This project allows users to convert long URLs into short, shareable links using the **TinyURL Public API**, manage recent links with Local Storage, and enjoy a beautiful glassmorphism user interface.

---

## ✨ Features

- 🔗 Shorten long URLs instantly
- ✅ URL validation before shortening
- 📋 Copy shortened URL with one click
- 🌐 Open shortened URL in a new browser tab
- 🕘 Recent Links History
- 💾 Local Storage support
- 🗑️ Delete individual history items
- ❌ Clear all history
- ⏳ Loading animation
- 🔔 Success & error notifications
- ⌨️ Press **Enter** to shorten URL
- 🎨 Modern Glassmorphism UI
- 🌈 Vibrant gradient background
- 📱 Fully responsive design
- ✨ Smooth hover effects and animations
- 🚀 No backend required

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- TinyURL Public API
- Local Storage API

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open **index.html** in any modern web browser.
4. Enter a valid long URL.
5. Click **Shorten URL** or press **Enter**.
6. Copy or open the generated short URL.
7. View and manage your recent links history.
